# Installation Notes

## Option A: Project-level skill
Place this folder in your project skills directory if your Claude Code setup supports project skills.

Suggested path:
.claude/skills/kelikuli-foreign-trade-website-builder/

## Option B: User-level skill
If you want this skill available for all projects, place it in your Claude skills folder according to your Claude Code installation.

## Basic use
After placing the folder, restart Claude Code or reload the session. Then ask:

"Use the Kelikuli foreign trade website skill to build my resin toy manufacturer website."

## Recommended workflow
1. Create or open your website project in VS Code.
2. Put this skill folder in the skills directory.
3. Start Claude Code in that project.
4. Paste the prompt from resources/claude_code_prompt.md.
5. Provide real product photos and factory data when available.
